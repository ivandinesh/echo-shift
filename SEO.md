# ECHO SHIFT — organic launch checklist

Canonical website: https://www.popdo.xyz/

## Implemented
- Unique descriptive HTML title and meta description
- HTTPS canonical, index/follow directive
- Open Graph and Twitter share metadata
- VideoGame JSON-LD structured data
- Indexable game introduction, how-to and FAQ content
- Robots and XML sitemap
- Mobile viewport and on-page accessible headings
- Social artwork at /social-card.svg
- Human-readable /README.md and /PLAN.md in GitHub

## Launch operations (manual account access required)
1. Add **https://www.popdo.xyz/** as a URL-prefix property in Google Search Console and verify domain ownership.
2. Submit **https://www.popdo.xyz/sitemap.xml**. Request indexing for the homepage once.
3. Register the site in Bing Webmaster Tools and submit the same sitemap.
4. Share a genuine product announcement linking to the canonical site, not its Vercel preview domain.
5. Measure real Core Web Vitals, mobile usability, and indexing coverage. Never assume a ranking or claim indexing before search engines confirm it.
6. Replace the SVG social artwork with a PNG/JPEG 1200×630 preview before relying on large social cards; major social crawlers may not accept SVG.
7. Export actual 192px/512px PNG icons and 180px Apple touch PNG; SVG icons alone are not reliable across install surfaces.
8. Run manual iOS Safari, Android Chrome, desktop keyboard, screen-reader, and airplane-mode playtests.

## Copy guidelines
- Be accurate: free browser puzzle, echo repeats input after two turns, 30 puzzles, daily/flow, no login, offline after first load.
- Do not invent player counts, reviews, awards, or ranking claims.
- Keep the homepage playable without a paywall, cookie wall, or forced sign-up.
- Publish new indexable pages only when they have distinct useful content.
